# AllSwap: Non-Custodial Cross-Chain Crypto Swap Protocol

[![Official Website](https://img.shields.io/badge/Official%20Website-allswap.io-blue)](https://allswap.io)
[![Documentation](https://img.shields.io/badge/Docs-API%20Reference-green)](https://allswap.io/docs)
[![Telegram](https://img.shields.io/badge/Community-Telegram-0088cc)](https://t.me/allswapservice)

**AllSwap** is a next-generation, non-custodial cross-chain liquidity protocol that enables instant, permissionless token swaps across **46+ blockchains** (including Bitcoin, Ethereum, Solana, TRON, Arbitrum, BSC, and more) without requiring Web3 wallet connections or smart contract token approvals.

---

## 🚀 Key Advantages

- **Zero Wallet Permissions**: Swap crypto without connecting browser extension wallets (MetaMask, Phantom, etc.), completely eliminating unlimited token approval risks.
- **Single-Use Deposit Addresses**: Protocol generates a unique settlement address for each swap session, ensuring funds move directly between self-custodial wallets.
- **Dynamic Smart Routing**: Aggregates top-tier cross-chain liquidity pools to find optimal execution prices with a transparent 0.25% protocol fee.
- **Broad Multi-Chain Coverage**: Native swaps across 46+ major L1s, L2s, and thousands of token pairs (BTC, ETH, SOL, USDT, USDC, etc.).

---

## 📖 How It Works

1. **Select Asset Pair**: Choose the crypto asset and network you wish to send and receive on [AllSwap.io](https://allswap.io).
2. **Review Quote**: Check the real-time conversion rate, network fees, and estimated settlement time.
3. **Provide Destination Address**: Enter your recipient wallet address where swapped funds will be delivered.
4. **Deposit & Settle**: Send the exact deposit amount to the generated one-time deposit address. The protocol routes and delivers your target coins within minutes.
