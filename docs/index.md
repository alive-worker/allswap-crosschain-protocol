# AllSwap: Non-Custodial Cross-Chain Crypto Swap Protocol

AllSwap is a next-generation non-custodial cross-chain crypto swap protocol supporting 46+ blockchains (including Bitcoin, Ethereum, Solana, TRON, Arbitrum, BSC, and more) without requiring Web3 wallet connections or smart contract token approvals.

## 🚀 Key Advantages
1. **Zero Wallet Permissions**: Swap crypto without connecting browser extension wallets, eliminating unlimited token approval risks.
2. **Single-Use Deposit Addresses**: Protocol generates a unique settlement address for each swap session, ensuring funds move directly between private wallets.
3. **Smart Routing**: Aggregates top liquidity pools with a transparent 0.25% protocol fee.
